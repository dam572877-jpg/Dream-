# DREAM HOUSE — MOBILE FLAGSHIP V8

Mobile-first real-estate management workspace for DREAM HOUSE.

## V8 highlights
- iPhone-inspired vertical glass navigation rail fixed to the right side on mobile.
- Navigation icons are stacked vertically and centered; no bottom navigation bar.
- Premium 3D/glass visual system across login, dashboard, property cards, clients and reports.
- Property selection works independently of the current PDF filter view.
- Selected property IDs are preserved while searching/filtering.
- PDF export rebuilt to paginate every selected property; 4 properties per report page, with no two-property truncation.
- 5, 6, 10 or more selected properties are all included in one multi-page PDF.
- Image export follows the same complete multi-page report.
- Local backup/restore remains available.
